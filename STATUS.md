# ORQEVIA status pointers

Read [the current source state](ORQEVIA-CURRENT-STATE.md) and
[the consolidated sweep](docs/ESTATE-SWEEP-20261106.md).
Source checks are not runtime verification.

The host checkpoint and actual acceptance receipts establish deployed versions,
service health, admission state and tested outcomes. A requirement, source edit,
historical manifest, model answer or CI result cannot establish those facts.

Each product owns its source, configuration, contracts, and domain records in its repository.
Preserve authentication, user isolation, secrets, HTTPS, user data, models and
rollback evidence. The wallet audit remains read-only; REA and MiroFish remain excluded.

Earlier portfolio status text is retained byte-for-byte in
`docs/history/status-authority-retirement-20261106/STATUS.md.txt`.
It is dated evidence, not current architecture or a pause instruction.
