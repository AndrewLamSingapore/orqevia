# Operational component references

Current portfolio status claims are recorded in [STATUS.md](../STATUS.md). Each product retains authority over its source, configuration, contracts, and domain records in its owning repository.

[operational-manifest.json](https://github.com/AndrewLamSingapore/prime/blob/main/governance/operational-manifest.json) is retained as a machine-readable component, release and observation reference only. It no longer selects current status, and it cannot promote anything to current or verified. Read [CHANNEL_CONTRACT.md](CHANNEL_CONTRACT.md) before interpreting it.

The generated human resume mirror is a machine-derived reference: it describes recorded observations, not current status. Reconcile status claims with the owning repository and observed runtime evidence. Historical documents, branches, and model memories do not prove current deployment. Source publication never proves ABEX/Dell deployment.
