# Evidence Product v0.1 — Afternoon Checklist

- [ ] Every consequential action receives a trusted action ID.
- [ ] Actor identity comes from system state, not model prose.
- [ ] Authority scope and source are independently recorded.
- [ ] Requested, invoked, observed and verified are separate states.
- [ ] Every material verified claim references evidence.
- [ ] Artifact digests are computed from actual bytes with named algorithm.
- [ ] Predictions are labeled and never promoted to observations automatically.
- [ ] Corrections append with an explicit canonical relation.
- [ ] Tenant/user namespaces are access-controlled.
- [ ] Receipts use deterministic serialization and validation.
- [ ] Secrets and unnecessary PII are excluded or redacted.
- [ ] Failure to capture evidence is reported as failure, never success.
- [ ] A false-success test and a tamper test pass.
- [ ] Normal result and Evidence view remain distinct.
