# God’s Eye / Semantic Fabric candidate — 7 October 2026

This extends the existing loopback production-control surface. It is a
read-only projection, not a new domain authority, agent, universal store or
certification mechanism. The actual 21 immutable registry identities are
retained; “A01–A21” is not used to invent or rename identities.

The browser never receives the server-side control token. Existing transport,
same-origin, Host and configured operator checks remain in force. This access
does not prove enrolled Owner/PWA/iPhone identity. No graph imports, raw SPARQL,
model invocation, evidence materialization or database migration is exposed.

Certification and HF inspection retain their existing explicit-bearer boundary.
An ordinary local browser view does not read these protected domains: missing
certification is UNKNOWN with a null L7 count, not 0/21. The existing authorized
operator can request the protected projection using the existing bearer header;
incorrect or duplicate headers fail closed rather than downgrading to ambient
access. The two projections cannot share cached private data. No token entry,
storage or forwarding is added to the browser.

Semantics uses checked-in Turtle, real RDFLib, pySHACL and bounded OWL-RL, fixed
typed queries and a small disposable cache. Historical, stale, invalid or
unsupported result projections are quarantined. Asserted/inferred statements,
reference integrity, verified capability and L7 remain different states.

Observation scope is at most 12 recent objectives, 50 queue rows, 48 result
contributions and a five-second process cache. Counts are window-scoped, not
lifetime productivity; missing quality/latency/cost/autonomy measurements stay
UNKNOWN. Host, deployment, rollback and real Owner gates are not passed by
runtime configuration or process liveness.

HF visibility reuses the existing authenticated HF observation contract and an
already-bounded Lens snapshot; it does not probe providers or repeat inference.
The profile distinguishes configured credentials, process-local circuit state,
dated execution, unmeasured role quality, and separate agent certification. All
21 current registered agents have optional HF applicability, not required HF
execution. Missing/invalid domain input stays UNKNOWN. The browser renders only
whitelisted fields and links to the existing task-scoped proof path.

The direct-QA rejection parser now uses strict decoded JSON and the shared
pre-execution error contract. Mixed/nested error/output, duplicate decoded
fields and nonfinite JSON cannot authorize fallback. Explicit provider model
pins reject dynamic `auto`, `fastest`, `cheapest` and `preferred` policies.
These are source repairs; they are not production DIRECT_QA acceptance.

Public HF discovery now has a bounded anonymous read-only interface: one Hub
GET with at most ten models and optionally one fixed model metadata GET. Its
ten-second deadline, per-response 98,304-byte cap, unique JSON keys, finite
numbers, no redirects/retries/cookies/environment proxy and allowlisted fields
are covered by 53 offline tests. One two-GET observation returned public model
and provider metadata without authentication or inference. Upstream provider
`live`, prices, feature hints and probe timings remain dated external assertions,
not PRIME authorization, quality, health or measured performance. Nothing is
automatically added to the catalog, dashboard polling or an agent's permissions.

Native HF policy routing is a separate open acceptance gate. Documented SDK
`provider="auto"` defaults to fastest; REST supports the bare model/default
fastest and `:fastest`, `:cheapest`, `:preferred` or explicit provider suffixes.
REST `:auto` was not present in the reviewed primary contract. Supporting those
policies safely still requires bounded price/privacy/provider-selection evidence;
the existing production pin guard is not relaxed by discovery alone.

The MLP execution wrapper reuses existing governed numeric inference contracts;
it does not register a new model, certify an agent or expose a new HTTP route.
Production-owned approval/capability verifiers, current runtime/certification
callbacks, durable model loading and evidence delivery still require binding.
Three bounded public MINI conversation/writing/planning oracles prepare real HF
trials; their 77 synthetic checks are validation coverage, not model quality.
