# Agent certification projection candidate

Source base: PRIME `origin/main` `9cc0f7c` (2026-10-04). This candidate adds a read-only projection over per-agent domain evidence directories. It does not add certification records, modify production, or grant execution authority.

`AgentCertificationRegistry(root, source_revision, verify_record=None)` reads `<root>/<agent_id>/certification.json` and referenced local evidence artifacts. With no authenticated verifier callback, all 21 registered agents project to L0 even if a file declares PASS. The projection also requires registered identity and owned capability, a different registered verifier, matching authority and source revision, current timestamps, distinct SHA-checked artifacts for required cases, and a bounded manifest/artifact size. A later FAIL, expired evidence, changed source revision, lost artifact, revoked verifier, or degraded health lowers the projected level or trust state.

Role certification requires separate normal, difficult, edge, invalid-input and failure case evidence. General certification requires separate evidence across analysis, planning, reasoning, communication, evidence handling, decomposition, artifact consumption/production, review, verification, error recognition, handoff and recovery. Baseline cases are also individual. L6 additionally requires collaboration, recovery, authority, tools, models, cross-verification, fresh challenge and healthy status.

Local source test: `tests/test_agent_certification.py`, 9 passed in 0.42s. Positive L1–L6 cases use synthetic temporary files and a test verifier callback solely to exercise projection rules; they are **not certification of a live agent**. There is no production evidence root or authenticated verifier integration in this candidate, so current certification remains 0/21 L6. Routing integration and live task demonstrations are separate work.
