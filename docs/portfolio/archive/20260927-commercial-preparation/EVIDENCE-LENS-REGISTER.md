## Evidence receipt requirements

Every future receipt must contain: receipt ID, product ID, experiment ID, date/time, participant classification, consent basis, evidence source, observed behavior, direct quote only with permission, artifact/reference, result, level before/after, reviewer, limitations, and cryptographic digest when stored as a file.

No level changes automatically. A conversation may establish L1; repeated independent problem evidence may establish L2; only actual use can establish L3; voluntary return usage L4; request for deeper use L5; payment L6; repeat payment L7; referral L8; repeatable measurable acquisition L9.
