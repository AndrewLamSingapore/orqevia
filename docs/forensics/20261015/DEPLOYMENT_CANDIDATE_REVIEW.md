The companion's three-second POST-body deadline (`security.py:24–34`) starts only after forwarding, so it does not protect this bridge stage. Add a bounded body-read deadline before accepting operational resource-budget qualification. Separately, urllib's socket timeout (`geo_ingest.py:316`) and httpx's phase timeout (`orqevia_bridge.py:47`) are not absolute end-to-end deadlines; do not describe them as a guaranteed total 20/25-second execution limit without elapsed-time enforcement.
