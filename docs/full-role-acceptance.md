# Full coaching and local role acceptance

The Owner's 13 October priority is complete coaching and acceptance of all 21
canonical agents, plus ORQEVIA orchestration. An inference call, a synthetic
oracle pass, a registered tool, or a completed controller session is insufficient.
Independent Azure L7 assessment remains separate and is never awarded here.

Each agent must retain its baseline, failed attempts, gap analysis, targeted
coaching, implementation repairs, reassessment, and original execution receipts.
Test normal execution, insufficient evidence, malformed inputs, and unauthorized
actions. Reassessment must include a different representative task with unchanged
responsibility criteria. Do not substitute a supplied correct answer for learning.

Every local acceptance decision requires all applicable criteria below, original
input and output hashes, actual model/provider identity, source and runtime pins,
real permitted tool execution and durable action records, output readback, and
an independent review. A score is a summary; it cannot override a failed required
criterion. Missing evidence is UNKNOWN, a prevented dependency is BLOCKED, and an
incorrect execution is FAIL. None can be counted as accepted.

The canonical a13 above is Forecast Agent. Historical aliases do not change
immutable identity or grant tool/authority rights.

ORQEVIA acceptance also requires authenticated objective routing to the correct
canonical role, enforced delegation relationships, one authoritative compute
queue, actual sink wiring, bounded local/cloud admission, retained artifacts,
accurate authenticated dashboard telemetry, restart continuity and conflict-free
coach ownership. A local deterministic fabric is not an additional hardware LLM
lane. Provider configuration and credentials alone are not capacity evidence.

Installed historical synthetic coaching retains its own source contracts and
assessment scope. New criteria do not rewrite its prompts, timestamps, costs,
failed outputs or PASS/FAIL outcomes. A separate end-to-end decision is required.
