## Measured capacity

One heavy inference remains the existing physical policy. Historical 28 October evidence observed 12B cgroup memory peaking at 14,487,719,936 bytes in a 15.29 GiB VM, and the independent scheduling-answer oracle FAILED. That result is retained and is not a quality acceptance.

This mission verified up to two inexpensive owned source-compilation processes, each bounded to one eligible logical CPU and 128 MiB declared working set. It did not qualify two arbitrary builds, parallel 12B generations, GPU inference, or sustained thermal load. In-process deterministic work should avoid per-role process startup when possible.

All inspected GitHub Actions workflows select ubuntu-latest or windows-latest hosted runners. No self-hosted runner or C++ compiler process was observed in the read-only process check. Existing CI is a suitable already-configured remote execution path; no new jobs, paid capacity, or private-source transmission were initiated for delegation.
